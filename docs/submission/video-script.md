# Countersign demo video (target 3:30, limit 4:00)

**Setup before recording**
- Use the live site: https://countersign-maanavkrishnas-projects.vercel.app (not localhost).
- Two browser windows side by side at 1440×900: left = "Grandma", right = an incognito window as "Ethan". Or film two phones.
- In Grandma's window: Family → pair with "Ethan"; open the link in Ethan's window and pair. Set trusted contact "Priya".
- Run each sample once beforehand so lookups are warm. Record the voiceover separately and lay it over the footage.
- Upload to YouTube as **Unlisted** and check the link in a private window.
