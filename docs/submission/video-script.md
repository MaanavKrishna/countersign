**One idea to land:** *AI can fake a voice. It can't fake our secret.* Everything else supports it.

**Setup before recording**
- Use the live site, https://countersign-maanavkrishnas-projects.vercel.app, on **two real phones** if you can ("Grandma" and "Ethan"). Two browser windows work too.
- On Grandma's phone: Family → **Start a family circle** ("Krishna family"; Grandma; others "Ethan, Priya"). Ethan scans the QR with his camera and taps "Ethan". Set trusted contact "Priya".
- Install the app on Grandma's Android phone (⋮ → Install app) if you can, to show the home-screen shortcut.
- Run "Check a message" once beforehand so lookups are warm.
- Record the voiceover separately. Upload to YouTube as **Unlisted** and check the link in a private window.
